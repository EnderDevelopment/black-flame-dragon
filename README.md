# Minecraft Plugin: Black Flame Dragon

Black Flame Dragon is a Minecraft plugin that transforms players into a black fire dragon using a clock, with black armor, flaming eyes, fire breathing, temporary flight, fire resistance, night vision, and increased speed.

## Install

1. Build the plugin with Java 21 and Maven:

   `mvn clean package`

2. Copy the generated `target/plugin.jar` file to your server's `plugins` folder.

3. Start or restart a Paper Minecraft server running version 1.21.11 or a compatible 1.21 version.

## Use

1. Hold a clock and right-click the air or a block to transform into a black fire dragon.
2. Sneak to launch a small fireball in the direction you are looking.
3. Jump once to activate flight. The plugin adds flame particles and an Ender Dragon wing sound.
4. Look at the player's face to see red and flame particles representing burning eyes.
5. Right-click with a clock again to return to normal form.
6. Leaving the server or disabling the plugin also restores the player's saved armor and removes the dragon effects.
